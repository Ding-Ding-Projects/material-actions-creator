# Keyboard and accessibility

| Keys | Action |
| --- | --- |
| Ctrl+Shift+F | Command palette: pages, commands and live settings |
| Ctrl+Shift+PageUp / PageDown | Previous / next tab |
| Arrow keys in the tab strip | Move between tabs |
| Delete on a tab | Close it |
| Shift+F10 or the Menu key | Context menu for the focused element |
| Shift+Enter | Confirm a destructive action after the slider |
| Escape | Close the open panel or dialog |

- Every control has a visible focus ring and a label for screen readers.
- Text size and density are in **Settings → Look**. The layout reflows down to 320 px wide.
- Motion follows your system's reduced-motion setting, and **Settings → Look → Motion** can turn it down further.
